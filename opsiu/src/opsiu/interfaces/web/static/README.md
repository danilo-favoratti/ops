# Local review assets

`review.css` belongs to OPSIU. The review interface uses system fonts and serves
all assets locally; it makes no CDN requests. The Python package includes the
ready-to-serve JavaScript files and requires no Node.js runtime or browser build.

`htmx.min.js` is the unmodified distribution from **HTMX 2.0.4**. The pinned
[official package metadata](https://raw.githubusercontent.com/bigskysoftware/htmx/v2.0.4/package.json)
identifies version `2.0.4` and license `0BSD`.

- Asset source: [official distribution](https://raw.githubusercontent.com/bigskysoftware/htmx/v2.0.4/dist/htmx.min.js)
- Asset size: `50917` bytes
- Asset SHA-256: `e209dda5c8235479f3166defc7750e1dbcd5a5c1808b7792fc2e6733768fb447`
- License source: [official Zero-Clause BSD license](https://raw.githubusercontent.com/bigskysoftware/htmx/v2.0.4/LICENSE)
- License copy: `htmx.LICENSE` (unmodified, `642` bytes)
- License SHA-256: `d3d2456f76414f2456104660ebd65aff1c04cd7966b942bdabd63f3cdb316a38`

The template configuration disables expression evaluation, inserted script tags,
external-origin HTMX requests, and HTMX's injected indicator stylesheet. The local
stylesheet supplies request indicators. Error responses can replace the decision
panel, and ordinary HTML forms support browsers without JavaScript.

To verify the vendored bytes from the product directory:

```sh
sha256sum src/opsiu/interfaces/web/static/htmx.min.js src/opsiu/interfaces/web/static/htmx.LICENSE
```

When upgrading HTMX, retrieve both files from the same official release, update
these hashes and sizes, and verify both enhanced and ordinary form submissions.

## PixiJS reimbursement graph

`pixi.min.js` is a custom, self-contained browser bundle of **PixiJS 8.22.0**
under the MIT license. Its global `PIXI` exposes only `Application`, `Circle`,
`Container`, `Graphics`, `Rectangle`, `Text`, and `VERSION`. It includes the
`pixi.js/unsafe-eval` compatibility module before renderer initialization:
despite its name, this module replaces dynamic function generation with static
implementations. The application retains `script-src 'self'`, without allowing
`unsafe-eval`, remote scripts, or runtime package downloads.

- Package: [official npm metadata](https://registry.npmjs.org/pixi.js/8.22.0)
- Source: [official npm tarball](https://registry.npmjs.org/pixi.js/-/pixi.js-8.22.0.tgz)
- Tarball integrity: `sha512-QbTANHMZ751MIjLiLSUSM8a7LNMWwMIf0KbRCqlW+SPS9hNLfSVS+cl1O2SEp9g1K/wyLzj/OJHv+1TUfiPr/w==`
- Compatibility source: [PixiJS static polyfills](https://github.com/pixijs/pixijs/blob/v8.22.0/src/unsafe-eval/init.ts)
- Initialization API: [PixiJS Application documentation](https://pixijs.download/v8.22.0/docs/app.Application.html)
- Asset size: `577383` bytes
- Asset SHA-256: `8be5d33d5937e28ba72aac0ddcdb41b0bed725a5222e400750a7a56b8ea4aca5`
- Combined license size: `8273` bytes
- Combined license SHA-256: `cf3b1da4c5b5797ec37209acc4a2991d76df327977c9ea43b46148cdf56d2574`

`pixi.LICENSE.txt` preserves the complete license notices for PixiJS and the
dependencies whose code survives bundling: `eventemitter3 5.0.4` (MIT),
`@pixi/colord 2.9.6` (MIT), `earcut 3.2.4` (ISC), `ismobilejs 1.1.1` (MIT),
`parse-svg-path 0.2.0` (MIT), and `tiny-lru 11.4.7` (BSD-3-Clause).

The developer-only build inputs live in `tools/pixi_vendor/`. They pin PixiJS
8.22.0 and esbuild 0.28.2, including all transitive integrity hashes in
`package-lock.json`. Build dependencies never ship in the Python package.
The colord package omits its license file; its unmodified notice is stored at
`tools/pixi_vendor/licenses/colord.LICENSE`, copied from the
[publisher's commit recorded in npm metadata](https://raw.githubusercontent.com/pixijs/colord/5344fbf77b736f81cd33c21050021bc09bc9dd1d/LICENSE.md).
Its SHA-256 is
`7613d4594ee8b6163926af3435dae61c9e3d5a27cd137bd76a543ba40002d8fc`.

To rebuild from the product directory with Node.js 18+ and npm:

```sh
cd tools/pixi_vendor
npm ci --ignore-scripts --no-audit --no-fund
node build.mjs
```

The build invokes the installed esbuild binary explicitly, produces a single
ES2020 IIFE without external imports, and regenerates the combined licenses.
It rejects changes to the set of bundled dependencies until their notices are
reviewed. Builds were reproduced with Node.js 24.18.0 and npm 11.16.0. Verify
the generated bytes from the product directory:

```sh
sha256sum src/opsiu/interfaces/web/static/pixi.min.js src/opsiu/interfaces/web/static/pixi.LICENSE.txt
```

When upgrading, update the pinned package and lockfile, inspect upstream changes
and license notices, regenerate both assets, update the hashes above, and test
graph rendering and interaction under the application's unchanged CSP.
